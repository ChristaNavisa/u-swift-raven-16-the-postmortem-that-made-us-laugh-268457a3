Entry for the make.fun bounty [The Postmortem That Made Us Laugh](https://make.fun/c/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3).

`main.ts` writes one short account — one or two sentences, at most 400
characters — of the silliest time an AI coding agent misunderstood its user,
to `/output/entry.txt`.

## Run

```sh
node main.ts
cat /output/entry.txt
```
